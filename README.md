## Doorlist

### What is Doorlist?

Doorlist is a full web application that is designed to simulate a concert/performance ticket sales site, akin to Ticketmaster.

It is a portfolio project and a practice exercise in delivering a fully fledged web service implementation using modern standards and protocols.
